# Admin cost surface

Operate mode. Administrators inspect ordinary chat and flow usage, distinguish measured charges from estimates, and follow summary → turn → measured request. Inherits frontend/src/theme.ts; no new visual identity. No marketing assets or fabricated live data.

## Direction contract

THESIS: Make the evidence behind a cost visible. Never collapse unknown dollars into a reassuring total.

OWN-WORLD: Existing Alliance application blue, neutral light surfaces, application typography, MUI controls, restrained borders and tabular numerals. Inherits the main app's light theme for daytime administrative reading; no new brand system.

STORY: Choose a window, see cost coverage, inspect conversations and flow runs, then export exact request-level evidence.

FIRST VIEWPORT: Compact application header with return link; title and deployment scope; labeled date/activity filters; recorded charges and independent estimated range side by side with coverage beneath; a conversation/turn table immediately below. Primary action is Apply filters. Drill-down changes the scope label explicitly and offers return to the window.

FORM: User-pinned summary-first structure, code-first. No concept seed: confirmed composition extends the established admin application. Signature interaction is a reversible drill-down with the active conversation/turn retained in the URL. Loading remains explicit; no decorative entrance motion.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
