# Phase C workflow invariants: ontology_term validator (bounded lookup path).
#
# Invariants are STRONGER than plain phrase retention: each line is an ordered step of
# the validator's bounded ontology lookup path. The invariant framework (1) reuses the
# retention assertion -- every line must appear in the assembled render -- and
# (2) asserts the lines appear in this same order by first occurrence, so the rewrite
# cannot scramble the
# curie-lookup -> terms-resolve -> paper-wording-search -> source-supported-variants ->
# apply-gates -> stop sequence.
#
# AUTHORING RULE (enforced by the harness): each phrase must occur EXACTLY ONCE in the
# assembled render and be listed in workflow order. These are verbatim from the
# <lookup_workflow> "Bounded lookup path" numbered block (steps 1-6). Sep 22 hotfix:
# the zero-results-means-unresolved step and the "do not keep searching" stop rule were
# replaced by a normal-mode search, bounded source-supported variants and an
# evidence-based stop (OTV-20..OTV-25 in docs/design/phaseC-checklists/ontology_term.md).

# Step 1 -- curie present: exact CURIE lookup.
If `curie` is present, call `get_ontology_term` first with `term=curie` and `ontology_term_type` when supplied.

# Step 2 -- terms present: resolve each item per the repeated-terms rule.
If `terms` is present, resolve each item independently and preserve input order per the repeated-`terms` rule below.

# Step 3 -- search the paper wording in normal mode.
Search the paper wording (`label`, otherwise `name`) with the selected helper, with synonyms on and `exact_match` false unless the request sets `exact_match: true`.

# Step 4 -- no fitting candidate: bounded source-supported variants.
If no candidate fits, search source-supported variants

# Step 5 -- after lookup: apply the prefix/allowlist/exact-match gates.
After lookup, apply the `accepted_prefixes`, `allowed_term_curies`, `unresolved_allowed_term_labels`, and `exact_match` gates below.

# Step 6 -- stop on a supported decision or indistinguishable candidates.
Stop when the evidence supports a decision, or bounded searches cannot distinguish the candidates.
